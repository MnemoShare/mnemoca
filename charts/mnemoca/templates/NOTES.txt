1. Operator API key. The key is never logged.
{{- if .Values.operatorApiKey.existingSecret }}
   Secret {{ .Values.operatorApiKey.existingSecret }} is adopted whenever the store has NO operator API key: on
   first start, and again as recovery if every operator key is ever lost. While an operator key
   exists it is ignored, and the server logs "bootstrap key <id> ... was not adopted".
   Rotate with POST/DELETE /api/v1/apikeys, then ROTATE OR REMOVE this Secret: after the old
   key is revoked and no other operator key remains, a restart would re-adopt it.
{{- else }}
   The server minted one into a 0600 file on the data volume. The image has no shell, so
   read it through an ephemeral container running as the same uid:

     echo '{"securityContext":{"runAsUser":65532,"runAsGroup":65532,"runAsNonRoot":true}}' > mnemoca-debug.json
     P=$(kubectl get pod -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=ca -o name | head -1)
     kubectl debug -n {{ .Release.Namespace }} -it $P --image=busybox:1.36 --target=mnemoca --custom=mnemoca-debug.json -- cat /proc/1/root/data/bootstrap-api-key

   Prefer operatorApiKey.existingSecret to avoid this.
{{- end }}
